# 英文单词深度解析项目约束

## 1. 项目目标

本项目用于解析用户输入的英文单词，并生成面向中文英语学习者的深度词条。输出应兼顾：

- 词义准确性；
- 实际英语中的自然程度；
- 常用搭配与句型；
- 近义词之间的使用边界；
- 写作、口语或考试中的可用性；
- 中英文例句的准确对应。

默认参照本项目提供的 `daunt` 示例的深度与组织方式，但不得机械套用不适合目标词的内容。

## 2. 输入处理

1. 默认输入是一个英文单词，也可以包含词形、词性、语境或学习目的等补充信息。
2. 如果输入的是屈折变化形式，应以其词典原形为主词条，并说明输入形式的语法功能。例如：输入 `daunted` 时，主词条按 `daunt` 解析，同时指出 `daunted` 可作过去式、过去分词或形容词。
3. 如果一个单词有多个常用词性或彼此明显不同的常用义项，应按词性和义项分别解析，不得只解释其中一个常见义。
4. 如果输入的拼写可能对应多个词，或拼写疑似错误，应先指出歧义或给出最可能的正确拼写，再继续解析；不得悄悄改词。
5. 如果用户提供了特定语境、考试类型或英语变体，应优先满足该要求；否则默认面向中高级中文学习者，并以当代通用英语为准。

## 3. 输出语言与总体风格

1. 解释和翻译使用简体中文；英文单词、搭配、句型和例句保留英文。
2. 语言应清楚、自然、具体，避免用另一个同样陌生的英文词代替解释。
3. 不只给中文对应词，还要说明该词表达的核心语义、典型语境、语气、正式程度和使用限制。
4. 优先描述真实、常见的现代英语用法。低频、过时、地域性或高度正式的用法必须明确标注。
5. 不为填满模板而虚构搭配、义项、音标变体、词形或语用差异。
6. 除非用户要求简版，否则输出应达到可独立用作学习笔记的完整程度。

## 4. 必须采用的输出顺序

每个词条原则上按照以下顺序组织。某一部分确实不适用时可以省略，但不得省略对理解和正确使用该词至关重要的内容。

### 4.1 标题与发音

- 标题直接写目标单词。
- 给出美式音标，格式为：`美式音标：/…/`。
- 如存在常见且可靠的美国发音变体，可补充说明；不要罗列罕见变体。
- 必要时可提醒重音、弱读、易错音或与相近单词的发音区别。

### 4.2 词性与释义

使用标题：`词性与释义`。

对每个常用词性分别提供：

- 词性标签必须同时附上对应的中文词性说明，不得只写英文缩写。例如：`verb [T]（及物动词）`、`verb [I]（不及物动词）`、`noun [C]（可数名词）`、`noun [U]（不可数名词）`、`adjective（形容词）`；若同一用法兼具两种语法属性，也应完整标明，如 `verb [T, I]（及物动词、不及物动词）`；
- 按常用程度排列的编号义项；
- 简洁的中文释义；
- 对核心语义、语气和适用场景的解释；如果某个编号义项在简洁释义之外还有额外说明，必须将说明写成 Markdown 引用块，即每个说明段落以 `>` 开头；
- 必要时说明“它不等于什么”或与直译的差异；
- 每个主要义项至少一个自然例句及准确中文翻译。

例句格式：

● The complexity of the application process **daunted** many students. 申请流程的复杂性使许多学生望而却步。

例句中的目标单词（包括其屈折变化形式）必须加粗；如果例句用于展示某个常用表达、固定结构或常用词组，应将该组合在英文例句中的完整对应部分加粗，而不只加粗其中的目标单词。

如果某个义项罕见、过时、专业化或只见于特定地区，必须明确标注。

### 4.3 实际使用概况

本部分必须按照以下优先级和顺序分析目标词，并列出各场景中最自然、最具代表性的常用表达方式：

1. **日常沟通交流使用频率**：先说明目标词在当代日常口语和一般交流中的使用频率，可使用“高频”“常见”“偶尔使用”“较少使用”等定性描述；随后列出日常交流中自然的常用表达。若母语者更常使用其他词、派生词或句型，应明确给出更自然的替代表达。
2. **雅思考试使用频率**：说明目标词在雅思听力、阅读等输入材料中，以及口语、写作等考生主动表达中的常见程度和适用性；随后列出适合雅思语境的常用表达。必须区分“可能在题目或文章中遇到”和“适合考生主动使用”，不得把生僻词强行推荐为高分词汇。
3. **标准英语新闻使用情况**：说明目标词在 CNN 等主流标准英语新闻报道中的常见程度、典型主题和语体；随后列出新闻报道中具有代表性的常用表达。不得仅凭单个例句宣称某种搭配“高频”。

以上三项均以真实、自然的表达为准。频率判断原则上使用定性描述；没有可靠语料或词典依据时，不得给出虚构的具体次数、百分比或排名。各场景中的表达先在本部分做简洁概览，详细语法限制和双语例句放入后续“常用表达”部分，以避免重复。

此外，综合说明以下信息中与目标词有关的部分：

- 正式、中性还是口语化；
- 在口语或书面语中的常见程度；
- 主动、被动或特定词形哪一种更自然；
- 当代英语是否更常使用其派生词、固定结构或近义表达；
- 该词通常描述人、事物、行为、情绪还是抽象概念。

应明确区分“语法上成立”和“母语者实际更常说”。

### 4.4 常用表达

使用标题：`常用表达`。

列出最有学习价值的句型或结构，每项包含：

1. 英文结构；
2. 中文功能说明；
3. 语义或语法限制；
4. 至少一个英文例句及中文翻译。

每项的英文结构必须直接使用 Markdown 粗体，不得使用反引号包裹成行内代码。格式示例：1. **sb be daunted by sth** 某人被某事吓倒或难住。

结构应尽量抽象成可复用形式，例如：

- **sb be daunted by sth**
- **find sth daunting**
- **be daunted by the prospect of doing sth**

必须正确使用 `sb`、`sth`、`doing sth`、介词和冠词，不得把偶然出现的词语组合误称为固定结构。

### 4.5 常用词组

使用标题：`常用词组`。

- 列出高频、自然、具有复用价值的搭配；
- 给出简洁中文意思；
- 对不透明、容易误用或特别重要的搭配补充例句；
- 优先收录真实搭配，不要把任意“形容词 + 名词”组合包装成固定词组。

每项常用词组的英文部分必须直接使用 Markdown 粗体，不得使用反引号包裹成行内代码。格式示例：1. **fixate on minor details** 过度关注细枝末节。

### 4.6 近义词辨析

使用标题：`近义词辨析`。

选择 2—5 个最容易与目标词混淆的近义词。每组辨析必须包含：

- 两者共享的大致语义；
- 最关键的区别，如原因、强度、结果、语气、搭配或使用对象；
- 对比例句及中文翻译；
- 在适合时给出简明选择规则，例如“如果强调……用 A；如果强调……用 B”。

不得只用中文近义词互换来制造区别。辨析必须能帮助学习者在具体句子中作出选择。

### 4.7 词形变化与词族

使用标题：`词形变化`。

按实际情况列出：

- 第三人称单数、过去式、过去分词、现在分词；
- 名词的单复数；
- 比较级和最高级；
- 常见派生名词、形容词、副词、否定形式；
- 发音容易发生变化的派生词音标。

仅列出确实存在且有现实使用价值的形式。低频形式须标注“较少使用”。不规则变化须明确提示。

### 4.8 常见错误与使用提示

使用标题：`常见错误与使用提示`。

优先检查并解释：

- 及物与不及物误用；
- 介词、动名词或不定式搭配错误；
- 可数与不可数错误；
- 主动与被动的自然程度；
- 与中文直译造成的误用；
- 与近义词句型的错误混用；
- 拼写、重音或词形错误。

尽量使用“错误或不自然表达 → 推荐表达”的形式，并说明原因。不要杜撰学习者并不常犯的错误。

### 4.9 学习或考试使用建议

根据目标词的特点给出简短、可执行的建议，例如：

- 更适合口语还是正式写作；
- 在雅思、托福、学术写作或日常交流中的自然用法；
- 哪个派生形式通常比原词更容易使用；
- 一个可直接迁移的高质量示例句。

如果该词不适合正式写作，或使用它不会自然提升表达质量，应如实说明，不得为了“高级词汇”效果而强行推荐。

## 5. 内容准确性约束

1. 音标使用 IPA，并以可靠的当代美式发音为准。
2. 中文翻译应传达原句语义和语气，不应机械逐词翻译。
3. 英文例句必须语法正确、语义自然，并能真正展示当前讲解的用法。
4. 同一词条中的解释、句型、例句和近义词辨析必须相互一致。
5. 不确定的信息不得写成确定事实。无法可靠确认时，明确说明不确定性或省略该内容。
6. 不引用不存在的词典规则、语料频率、地域差异或专家观点。
7. 若涉及可能变化的当代用法、频率判断或地域差异，在具备检索能力时应优先核实可靠词典或语料来源。

## 6. 例句约束

1. 每个例句只承担一个主要教学目的，避免同时塞入多个复杂知识点。
2. 例句应覆盖有代表性的场景，可包括教育、工作、社会议题和日常生活，但不得全部写成同一种题材。
3. 例句难度应与目标词匹配，避免为了显得高级而使用大量无关生词。
4. 中英文例句必须位于同一条目中，先英文，后中文。
5. 除非是在展示错误，例句不得包含不自然搭配。
6. 若展示错误句，必须明确标记为 `不推荐`、`错误` 或 `不自然`，并紧接推荐改法。
7. 英文例句中的目标单词或其词形变化必须使用 Markdown 粗体；用于演示常用表达、固定结构或常用词组时，应加粗该组合在例句中的完整形式。例如：`She was **daunted by the scale of the task**.`。近义词对比例句中，也应加粗该句正在展示的目标词或近义词。

## 7. 篇幅与取舍

1. 常用且多义的词可以写得更详细；义项单一或低频的词应适当缩短。
2. 不重复解释同一语义。相同信息只保留在最合适的章节，并在其他章节补充新的使用价值。
3. 常用表达和常用词组以质量优先，通常各列 3—8 项；确实不足时不强行凑数。
4. 近义词只选真正容易混淆、能形成有效对比的词。
5. 输出应完整，但避免词典式堆砌所有罕见义项和边缘搭配。

## 9. 最终检查清单

输出前逐项确认：

- 音标、重音和词形是否正确；
- 每个词性标签后是否写明了对应的中文词性说明；
- 是否覆盖主要常用词性和义项；
- 是否解释了核心语义，而非只给中文翻译；
- 编号义项后的额外说明是否使用了 Markdown 引用格式；
- 搭配和句型是否真实、自然、可复用；
- “常用表达”中的英文结构是否使用粗体且未使用行内代码格式；
- “常用词组”中的英文部分是否使用粗体且未使用行内代码格式；
- 每个主要用法是否有中英双语例句；
- 英文例句中的目标词、词形变化或正在展示的完整常用组合是否已加粗；
- 近义词区别是否具体且能指导选择；
- 是否指出正式程度、常见语态或现实使用倾向；
- “实际使用概况”是否依次覆盖日常交流、雅思考试和标准英语新闻，并列出各场景的自然常用表达；
- 频率判断是否采用有依据的定性描述，且没有虚构具体频次或排名；
- 是否避免把 `daunt` 示例中的特点机械迁移到其他单词；
- 是否删除了重复、罕见且无学习价值的内容；
- 是否明确标记错误句、低频形式和不确定信息。

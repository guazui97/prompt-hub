# 英文单词深度解析项目约束

## 1. 项目目标

本项目用于解析用户输入的英文单词，并生成面向中文英语学习者的深度词条。输出应兼顾：

- 词义准确性；
- 实际英语中的自然程度；
- 常用搭配与句型；
- 近义词之间的使用边界；
- 写作、口语或考试中的可用性；
- 中英文例句的准确对应。

默认参照本项目提供的 `daunt` 示例的深度与组织方式，但不得机械套用不适合目标词的内容。

## 2. 输入处理

1. 默认输入是一个英文单词，也可以包含词形、词性、语境或学习目的等补充信息。
2. 如果输入的是屈折变化形式，应以其词典原形为主词条，并说明输入形式的语法功能。例如：输入 `daunted` 时，主词条按 `daunt` 解析，同时指出 `daunted` 可作过去式、过去分词或形容词。
3. 如果一个单词有多个常用词性或彼此明显不同的常用义项，应按词性和义项分别解析，不得只解释其中一个常见义。
4. 如果输入的拼写可能对应多个词，或拼写疑似错误，应先指出歧义或给出最可能的正确拼写，再继续解析；不得悄悄改词。
5. 如果用户提供了特定语境、考试类型或英语变体，应优先满足该要求；否则默认面向中高级中文学习者，并以当代通用英语为准。

## 3. 输出语言与总体风格

1. 解释和翻译使用简体中文；英文单词、搭配、句型和例句保留英文。
2. 语言应清楚、自然、具体，避免用另一个同样陌生的英文词代替解释。
3. 不只给中文对应词，还要说明该词表达的核心语义、典型语境、语气、正式程度和使用限制。
4. 优先描述真实、常见的现代英语用法。低频、过时、地域性或高度正式的用法必须明确标注。
5. 不为填满模板而虚构搭配、义项、音标变体、词形或语用差异。
6. 除非用户要求简版，否则输出应达到可独立用作学习笔记的完整程度。

## 4. 必须采用的输出顺序

每个词条原则上按照以下顺序组织。某一部分确实不适用时可以省略，但不得省略对理解和正确使用该词至关重要的内容。

### 4.1 标题与发音

- 标题直接写目标单词。
- 给出美式音标，格式为：`美式音标：/…/`。
- 如存在常见且可靠的美国发音变体，可补充说明；不要罗列罕见变体。
- 必要时可提醒重音、弱读、易错音或与相近单词的发音区别。

### 4.2 词性与释义

使用标题：`词性与释义`。

对每个常用词性分别提供：

- 词性标签必须统一使用 Markdown 三级标题，并同时附上对应的中文词性说明，不得只写英文缩写。例如：`### verb [T]（及物动词）`、`### verb [I]（不及物动词）`、`### noun [C]（可数名词）`、`### noun [U]（不可数名词）`、`### adjective（形容词）`；若同一用法兼具两种语法属性，也应完整标明，如 `### verb [T, I]（及物动词、不及物动词）`；
- 各词性下的义项必须统一使用不加粗的编号正文形式，如 `1. [中文释义]`，不得把单个义项写成任何级别的 Markdown 标题，也不得对义项名称使用 Markdown 粗体；
- 每个词性只收录当代英语中最常用的义项，以及雅思考试中考频最高、最有学习价值的少数义项；不要为了追求完整而罗列大量低频、专业化或边缘义项；
- 简洁的中文释义；
- 每个义项分成三个层次：第一层是编号后的简洁中文释义，使用普通正文，不加粗且不使用引用格式；第二层是该义项的详细中文说明，用于解释核心语义、语气、适用场景及必要的使用边界，必须统一使用 Markdown 引用块，即每个详细说明段落以 `>` 开头；第三层是双语例句，放在引用说明之后，不纳入引用块；不得把简洁中文释义或例句放入引用块；
- 必要时说明“它不等于什么”或与直译的差异；
- 每个主要义项至少一个自然例句及准确中文翻译。

例句格式：

● The complexity of the application process **daunted** many students. 申请流程的复杂性使许多学生望而却步。

例句中的目标单词（包括其屈折变化形式）必须加粗；如果例句用于展示某个常用表达、固定结构或常用词组，应将该组合在英文例句中的完整对应部分加粗，而不只加粗其中的目标单词。

如果某个义项罕见、过时、专业化或只见于特定地区，必须明确标注。

### 4.3 实际使用概况（含常用表达）

本部分合并原“实际使用概况”和“常用表达”，不再另设独立的“常用表达”章节。必须按照以下顺序分析目标词，并在每个场景下列出少量最有学习价值的表达：

1. **日常沟通交流**：列出日常口语和一般交流中最自然、最有学习价值的少量表达。若母语者更常使用其他词、派生词或句型，应明确给出更自然的替代表达，但不展示“高频”“常见”“偶尔使用”等使用频率标签。
2. **雅思考试**：列出雅思听力、阅读、口语或写作中最值得掌握的少量表达，并说明其适用场景和主动使用边界；不得把生僻词强行推荐为高分词汇，也不展示使用频率。
3. **标准英语新闻**：列出 CNN 等主流标准英语新闻中具有代表性的少量表达，并说明典型主题和语体，不展示常见程度或使用频率。

以上三类场景统一采用以下展示形式：

1. 每个场景标题下先放一段简洁的中文概览，说明该词在此场景中的主要用途、适用语体、自然表达倾向或总体使用边界；概览必须使用 Markdown 引用块，即每个段落以 `>` 开头。
2. 随后用编号正文列出表达，格式为 `1. **[英文结构]** [中文含义或交际功能]`；英文结构必须直接使用 Markdown 粗体，不得使用反引号。
3. 每一项具体表达下都必须单独提供一段中文用法介绍或注意事项，并使用 Markdown 引用块。该说明应聚焦当前表达的搭配限制、语义边界、正式程度、替代表达或易错点，不得省略，也不得提供英译英释义。
4. 大类概览与具体表达说明必须分工明确：大类概览说明整个场景的总体特点，具体说明只解释当前表达，避免原句重复。
5. 每项表达的中文引用说明之后，至少提供一个自然英文例句及准确中文翻译；例句使用 `●` 开头，并将正在展示的完整表达加粗。

每类场景只选择少量表达，优先收录外国学习者最容易弄错的用法和雅思考试最常考、最适合主动使用的结构，不做大而全的罗列。本部分不得展示定性或定量的使用频率，不得给出具体次数、百分比或排名。

此外，应把以下相关信息按需融入对应场景的中文概览，不另写独立总结段落：

- 正式、中性还是口语化；
- 更适合口语还是书面语；
- 主动、被动或特定词形哪一种更自然；
- 当代英语是否更常使用其派生词、固定结构或近义表达；
- 该词通常描述人、事物、行为、情绪还是抽象概念。

应明确区分“语法上成立”和“母语者实际更常说”，但不得将其写成使用频率评价。

### 4.4 常用词组

使用标题：`常用词组`。

- 只列出少量高频、自然、具有复用价值的搭配，优先选择外国学习者容易误用或雅思考试中常见的词组；
- 给出简洁中文意思；
- 对不透明、容易误用或特别重要的搭配补充例句；
- 优先收录真实搭配，不要把任意“形容词 + 名词”组合包装成固定词组。

每项常用词组的英文部分必须直接使用 Markdown 粗体，不得使用反引号包裹成行内代码。格式示例：1. **fixate on minor details** 过度关注细枝末节。

### 4.5 近义词辨析

使用标题：`近义词辨析`。

按照雅思考试中的出现和使用频率，以及外国学习者的实际混淆程度进行选择。通常只选 2—3 个最值得比较的近义词；若只有一个真正有价值的对比，也不强行凑数。每组辨析必须包含：

- 两者共享的大致语义；
- 最关键的区别，如原因、强度、结果、语气、搭配或使用对象；
- 对比例句及中文翻译；
- 在适合时给出简明选择规则，例如“如果强调……用 A；如果强调……用 B”。

不得只用中文近义词互换来制造区别。辨析必须能帮助学习者在具体句子中作出选择。

### 4.6 词形变化与词族

使用标题：`词形变化`。

按实际情况列出：

- 第三人称单数、过去式、过去分词、现在分词；
- 名词的单复数；
- 比较级和最高级；
- 常见派生名词、形容词、副词、否定形式；
- 发音容易发生变化的派生词音标。

仅列出确实存在且有现实使用价值的形式。低频形式须标注“较少使用”。不规则变化须明确提示。

### 4.7 学习或考试使用建议

根据目标词的特点给出简短、可执行的建议，例如：

- 更适合口语还是正式写作；
- 在雅思、托福、学术写作或日常交流中的自然用法；
- 哪个派生形式通常比原词更容易使用；
- 一个可直接迁移的高质量示例句。

如果该词不适合正式写作，或使用它不会自然提升表达质量，应如实说明，不得为了“高级词汇”效果而强行推荐。

## 5. 内容准确性约束

1. 音标使用 IPA，并以可靠的当代美式发音为准。
2. 中文翻译应传达原句语义和语气，不应机械逐词翻译。
3. 英文例句必须语法正确、语义自然，并能真正展示当前讲解的用法。
4. 同一词条中的解释、句型、例句和近义词辨析必须相互一致。
5. 不确定的信息不得写成确定事实。无法可靠确认时，明确说明不确定性或省略该内容。
6. 不引用不存在的词典规则、语料频率、地域差异或专家观点。
7. 若涉及可能变化的当代用法、频率判断或地域差异，在具备检索能力时应优先核实可靠词典或语料来源。

## 6. 例句约束

1. 每个例句只承担一个主要教学目的，避免同时塞入多个复杂知识点。
2. 例句应覆盖有代表性的场景，可包括教育、工作、社会议题和日常生活，但不得全部写成同一种题材。
3. 例句难度应与目标词匹配，避免为了显得高级而使用大量无关生词。
4. 中英文例句必须位于同一条目中，先英文，后中文。
5. 除非是在展示错误，例句不得包含不自然搭配。
6. 若展示错误句，必须明确标记为 `不推荐`、`错误` 或 `不自然`，并紧接推荐改法。
7. 英文例句中的目标单词或其词形变化必须使用 Markdown 粗体；用于演示常用表达、固定结构或常用词组时，应加粗该组合在例句中的完整形式。例如：`She was **daunted by the scale of the task**.`。近义词对比例句中，也应加粗该句正在展示的目标词或近义词。

## 7. 篇幅与取舍

1. 即使目标词常用且多义，“词性与释义”也只保留最常用和雅思考频最高的少数义项；低频、专业化、过时或边缘义项原则上省略，除非其对理解目标词至关重要。
2. 不重复解释同一语义。相同信息只保留在最合适的章节，并在其他章节补充新的使用价值。
3. 合并后的“实际使用概况”中，每类场景的表达以质量优先，通常列 1—3 项；只保留外国学习者容易弄错或雅思考试高频、有主动使用价值的表达。
4. 常用词组通常列 3—5 项；近义词通常选择 2—3 个，均不得为了凑数而收录低价值内容。
5. 输出应完整，但避免词典式堆砌所有罕见义项和边缘搭配。

## 9. 最终检查清单

输出前逐项确认：

- 音标、重音和词形是否正确；
- 每个词性标签后是否写明了对应的中文词性说明；
- 是否只保留最常用及雅思考频最高、最有学习价值的少数词性和义项；
- 是否解释了核心语义，而非只给中文翻译；
- “词性与释义”中的词性标签是否统一使用三级标题，各词性下的编号义项是否统一使用不加粗的正文形式，且未使用 Markdown 标题；
- 每个义项是否依次采用“普通正文的简洁中文释义 → 引用格式的详细中文说明 → 引用块外的双语例句”，且只有详细说明使用引用格式；
- 搭配和句型是否真实、自然、可复用；
- “实际使用概况”是否已经合并常用表达，且没有保留独立的“常用表达”章节；
- 日常交流、雅思考试和标准英语新闻三类场景是否均先用中文引用块概述主要用法，再用编号正文列举少量表达；
- 每项表达是否按“粗体英文结构＋中文含义”的形式呈现，并且无一例外地配有独立的中文引用说明；
- 大类中文概览是否说明整个场景的总体特点，而每项表达的中文引用说明是否只针对当前表达，二者是否避免原句重复；
- 每项表达是否配有至少一个以 `●` 开头的双语例句；
- “实际使用概况”中是否已删除使用频率展示和英译英释义；
- 各场景中的表达是否只选外国学习者容易弄错或雅思考试高频、有主动使用价值的少数内容；
- 各场景表达中的英文结构是否使用粗体且未使用行内代码格式；
- “常用词组”中的英文部分是否使用粗体且未使用行内代码格式；
- 每个主要用法是否有中英双语例句；
- 英文例句中的目标词、词形变化或正在展示的完整常用组合是否已加粗；
- 近义词是否依据雅思考频和外国学习者的混淆程度精选，且区别具体、能够指导选择；
- 是否指出正式程度、常见语态或现实使用倾向；
- “实际使用概况”是否依次覆盖日常交流、雅思考试和标准英语新闻，并列出各场景的自然常用表达；
- 是否避免把 `daunt` 示例中的特点机械迁移到其他单词；
- 是否删除了重复、罕见且无学习价值的内容；
- 是否已移除“常见错误与使用提示”章节；
- 是否明确标记低频形式和不确定信息。
